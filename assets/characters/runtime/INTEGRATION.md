## 无损提取与去重

`tools/build-character-assets.cjs` 提取静态蒙皮模型，动画时间与数值数组按内容哈希只存一次，仍为每个角色保存自己的轨道索引。模型保留网格、材质、原纹理、逆绑定矩阵、骨骼和 Socket；没有压图、减面或把别人的完整动画强套到新骨架。

`manifest.js` 的通用动作元数据来自 deepseek；不同角色的 `animationOverrides` 保留实际动作速度、事件和根运动信息。`characters.js` 为每个实例合并自己的元数据，已缓存的上半身剪辑也绑定正确的角色元数据。

## 第一人称持握基准

三名角色的世界比例均保持 2 倍，但绑定姿势与手部位置不同。2026-11-08 实测旧统一偏移让真·Claude 的枪械原点比 deepseek 高约 0.19 米，形成枪身顶到画面上方的现象。

`characters.js` 创建第一人称实例时，用独立临时 Mixer 采样该角色自己的 `RifleIdle` 第 0 帧，测量 `Socket_Weapon` 与现有枪械握点的组合世界位置，将整个双臂根节点对齐到共同参考 `(-0.03, 0.10, -0.04)`。结果按角色 ID 缓存；采样后还原骨架并释放临时 Mixer，再由正式 Mixer 播放动作。狙击枪另整体下移 0.05 米、前移 0.12 米，为长枪与瞄准镜留出画面空间。不要只移动枪械而让手留在原处，也不要在 `game.ensurePlayerCharacter()` 再写固定根节点偏移。

武器继续挂原 Socket，握持、换弹、投雷和换枪沿用同一套骨骼关系。世界角色、命中胶囊、第三人称尺寸与阴影不缩放。持狙击枪期间普通准星隐藏；镜内瞄准刻度、命中反馈继续使用原 UI。后续增加新比例角色应核查该中立姿势、双手握点、袖口和各武器动画，而不是直接复制现有角色的相机偏移。

## 程序瞄准与头部投影

2026-11-08 修复第一人称低头时头部影子不断旋转：`AnimationMixer` 对结果未变化的轨道会跳过写回骨骼，而旧代码直接在颈部当前四元数上逐帧 `rotateX()`，导致相机俯仰无限累加；时间为 0 的姿势同步也会触发。

`characters.js` 现在把 Chest / Neck 的程序瞄准视为动画之后的一层：保存本帧动画姿势 → 应用一次俯仰 / 枪口瞄准 → 下次混合动画前恢复保存值。换武器、近战开始和重置也先恢复；公开 `aimAt()` 重复调用不继续叠加。不要假定 Mixer 一定会在下一帧覆盖程序修改，也不能用关闭头部投影掩盖骨骼错误。

冻结尸体时先保存最终已瞄准姿势，再清理活体瞄准标记，确保布娃娃接收到死亡瞬间姿势；复制姿势和复活重置不继承陈旧偏移。材质隐藏、完整人物投影与第一人称双臂规则保持原实现。回归脚本：`tests/browser-head-shadow-test.cjs`，覆盖三角色、30 / 60 / 144 FPS、走动 / 静止、俯仰、换弹、投雷、近战、尸体及真实地面投影。

护目镜头部减伤 20%，耐久 4，第四次仍保护，耗尽后失效并移除模型；身体伤害和没有部位判定的爆炸不消耗它。头部刀刃命中也传入对应受击信息。复活恢复装备耐久与外观。模型已接入用户提供的三种头型版本，见 [护目镜接入说明](../../equipment/GOGGLES_INTEGRATION.md)。

`js/recon-fx.js` 将本地敌方活体蒙皮绘入独立遮罩，再合成金色轮廓；不加入墙体深度，所以可穿墙显示。代理共享原网格 / 骨骼，保留原 `bindMode` 和世界变换，不能改成 detached 后重复应用世界变换。队友与尸体不进入遮罩，伤害射线和 AI 的遮挡判定完全独立。效果结束清除代理，卸载场景释放 RenderTarget 与材质。

AI 使用相同角色、装备、狙击开镜资格与 3 秒 / 60 秒时长，在有效期间采样全场敌方位置，结束后只保留最多 6 秒的历史快照。信息不自动广播给队友，不允许向被墙遮挡的目标开枪。AI 的 `recon.readyAt` 保存在角色实体上，脑状态和复活重置不能清掉它。详细决策与装备随机规则见 [狙击与侦察 AI 说明](../../../FPS_狙击与侦察AI说明.md)。

## 投雷与空中动作

`GrenadeThrow` 原始时长 1.8 秒，拔销 0.5667 秒、出手 1.1 秒、收招完成 1.8 秒。现在按 4 进入持雷姿势；左键按下启动 3 秒引信，松开时立即在手部 Socket 生成弹体，同时将动画定位到原 1.1 秒出手帧并继续收招，不等待动画产生延迟。收招结束前禁止攻击 / 换弹 / 切枪。第三人称投掷上半身与下半身走跑 / 蹲行 / 滞空分层，第一人称仍只显示双臂。AI 没有玩家松键输入，继续按原 1.1 秒事件出手。起跳、实际移动速度继续进入弹道。

拔销前死亡不会凭空产生活雷；拔销后、出手前死亡掉落一颗已预热手雷；已经出手的手雷不会再次掉落。暂停、复活、回合切换及退出清理动作和手中模型。玩家与 AI 共用相同动作事件和物理弹体。

世界角色和第一人称双臂都读取实际 `grounded`。空中移动使用 JumpStart / JumpLoop，落地先完成 JumpLand 再恢复地面走跑；不再把第一人称强制当作站在地面。

FPS 手雷半径 **7.5 米**（原 5 米）；无尽最终技能 / 环境半径也乘 1.5。爆炸视觉尺寸同步扩大 50%，基础伤害不变。AI 只对视锥内且无遮挡的敌人考虑投雷，模拟落点与反弹、排除贴身和友军危险落点；每次生命一颗，投掷期间停止移动和射击。

语音接入与空间音频见 [声音说明](../../sfx/VOICE_INTEGRATION.md)。进一步更新角色时，优先保持骨骼 / Socket 命名兼容；出现新比例时重新核对头盔、受击胶囊和持握位置，不应直接套用另一个角色的全部动画数值。
