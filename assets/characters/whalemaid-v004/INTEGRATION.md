## 实机形象与动作

无尽普通近战、射手、盾兵、自爆、治疗、分裂及分裂子怪统一使用新模型，以现有武器和特种附件区分类别。FPS 双方 AI 与本地玩家身体也使用新模型。旧立绘占位不再挂在这些实机角色上；仓库/大厅现在只开放此模型角色，名称为 deepseek娘，使用实际模型渲染的预览；旧三种图片角色选择已移除，其他六个角色仅预告。无尽 Boss 保持原图片形象。

`js/characters.js` 负责资源缓存、独立骨骼克隆、动作混合、武器握点和受击胶囊。每个实例具有独立 AnimationMixer，角色间共享几何、材质和贴图；同一实例的三个网格共用一套骨骼纹理。16v16 正常为 31 个 AI + 玩家世界身体 + 玩家第一人称手臂，共 33 个实例；本地玩家死亡时临时增加一具完整尸体。

行走/跑步/后退/侧移、蹲姿、起跳/落地由实际运动驱动。枪械开火使用上半身叠加动作，换弹使用上半身动作与下半身移动分层。敌人朝交战目标转动胸部与双臂，枪口从实际武器锚点读出。原动作蹲下为 0.105 米，运行时相机下移 0.21 米与之匹配。

**第一人称可见性（同日修订）**：独立第一人称实例只绘制 `Mesh_Arms` 和武器。玩家世界实例始终保留完整的三个网格及武器，不再隐藏其中的头或手臂。`game.js` 的 `renderGameView` 仅在本地相机绘制期间隐藏世界实例，并在 `finally` 中恢复；独立旁观相机绘制完整身体，并隐藏相机绑定的第一人称武器/手臂，避免重复。角色动画、受击胶囊及完整尸体不受相机隐藏影响。直接使用渲染器绘制额外视角时，也应遵守这个按视角处理的入口。

**FPS 死亡镜头（同日追加）**：先保存倒地瞬间的位置和朝向，再平滑拉到自身布娃娃躯干周围。鼠标只控制环绕，不改变玩家位置；左键才选择存活队友，右键返回自身。环绕中心读取本地布娃娃的躯干刚体位置，镜头臂做带 0.16 米余量的地图碰撞裁剪。清理、复活、重开时同步清空观战状态，不能让相机继续持有被释放的角色引用。

**FPS AI 跳跃**：`fps-locomotion.js` 使用玩家扫掠碰撞器，120 Hz 固定子步；当前身体净空 1.9 米、半径 0.46 米、初速度 9.2 米/秒、重力 -21 米/秒²。导航只纳入经完整模拟确认能落地的低掩体连接；起跳和滞空期间由实际 `onGround` 驱动对应动作，世界模型高度不再逐帧归零。空中死亡将运动速度交给布娃娃，复活重新设置为地面状态。该跳跃树用于 FPS，普通无尽敌人的原行为保持。

**握点校准须保留**：文档中描述武器局部 +Z 朝前，但实际 v004 GLB 导出的 Socket_Weapon / Socket_Melee 沿局部 +Y 持械。接入时在武器上设 `rotation.x = -Math.PI / 2`，把程序化武器 +Z 转到 Socket +Y。长剑动作中，左手腕转换到武器局部约为 `(0.020, 0, -0.037)`，与副握点吻合；枪口方向已实测。不要仅按原说明删掉这一旋转，否则会出现枪口朝下、长剑脱手。

## 部位受击

每个完整角色使用 16 个随骨骼变动的胶囊，长发、裙摆、耳饰不作为额外受击面积。胶囊配置在 `characters.js` 的 `specs`，倍率统一在 `character-hitboxes.js` 的 `multipliers`。

| 身体部位 | 伤害倍率 |
| --- | ---: |
| 头 | 1.75 |
| 胸、腹 | 1.00 |
| 骨盆 | 0.90 |
| 上臂 | 0.70 |
| 前臂 | 0.65 |
| 手 | 0.50 |
| 大腿 | 0.80 |
| 小腿 | 0.70 |
| 脚 | 0.50 |

射线取最先接触的胶囊，而非按屏幕高度推断爆头。玩家、FPS AI 与无尽射手都采用该规则；腿间空隙可以穿过，蹲姿、跳跃与动作会改变受击位置。枪械原有距离衰减、护甲和模式规则继续适用。范围爆炸、辐射不乘部位倍率。Boss 图片继续采用原枪击体积，近战另有躯干胶囊。

这些是**战斗受击胶囊**；角色行走由玩家扫掠碰撞、AI 地面导航/局部分离与新增的跳跃控制器处理。活人没有使用死亡布娃娃的刚体关节控制器；受击体积和地图移动代理各有用途。

## 近战体积与伤害

`FishCombat.rigBlade` 的可见刀刃与 `userData.blade` 共用尺寸。胶囊由刃根、刃尖和刃宽得到；当前匕首刃长 **0.49 米**，长剑 **1.04 米**。这不是角色的完整攻击距离，手臂伸展、朝向和挥砍轨迹也参与触及判定。

- 只在 manifest 的 `active_start`～`active_end` 期间计算接触，预备和收招阶段不造成伤害。
- 匕首轻击 0.6 秒，有效窗 0.192～0.336 秒；重击 1.4 秒，有效窗 0.798～1.078 秒。
- 使用前后帧刀刃与身体胶囊的相对运动扫掠；动画攻击时按不大于 1/60 秒的子步推进，低帧率不会仅检查结束姿势。
- 一次挥砍对同一目标只结算一次；刀刃和攻击者到接触点的墙体遮挡均检查。切枪、死亡、复活和重开取消旧动作；暂停冻结。
- 基础伤害：`实际世界刃长 × 模式每米系数 × (重击 ? 1.85 : 1) + 无尽强化`，随后乘部位倍率，无尽玩家再乘连杀增益。系数 FPS 为 68、无尽玩家为 4.1、无尽普通敌人为 28；敌人成长作为附加值继续接入。
- 因而当前 FPS 匕首躯干轻击约 33.32、重击约 61.64；无尽无强化约 2.01 / 3.72。数值从模型刃长计算，不能再新增固定 35/65 或 2.6 米范围判定。
- 近战敌人、FPS AI 和保留图片的冲锋 Boss 都接入刀刃接触；Boss 继续用其原大剑模型的实际刀刃尺寸。

## 布娃娃

`js/ragdolls.js` 使用独立 cannon-es 世界。死亡瞬间保存当前动作姿势，停止混合器，以现有骨骼构建 **14 个胶囊刚体、13 个锥扭关节**，随后由刚体驱动蒙皮。120 Hz 固定物理子步，包含重力、阻尼、碰撞摩擦、睡眠及死亡方向冲量；自爆会增加向上冲量。

| 场景 | 尸体清理 |
| --- | --- |
| FPS AI、本地玩家 | 该角色复活时移除；回合重新部署、离开场景也清理 |
| 无尽普通敌人、分裂子怪、自爆怪 | 死亡后 5 秒移除；刷新下一波不会提前清理 |
| 无尽本地玩家 | 失败界面下继续倒地，5 秒移除；重开立即清理 |
| 无尽 Boss | 本轮仍为图片，没有可驱动的完整骨骼，继续原退场方式 |

清理计时以对局时间为准，暂停冻结。尸体不再参与 AI、伤害或占据复活位置。物理体与地面、原地图实体障碍碰撞；刷新随机掩体时同步静态碰撞，重开释放旧世界。尸体消失同时移除刚体、关节和独有骨骼资源，不销毁共享贴图。

为控制多人场景开销，关闭尸体之间以及同一尸体各肢体之间的接触；关节约束及与地图的接触继续求解。头发/裙摆跟随骨骼，没有单独的布料或头发物理。不能把本实现描述为完整软体或布料模拟。

## 验证与后续开发

新增 `tests/character-hitboxes-test.cjs`、`tests/browser-character-test.cjs`、`tests/browser-ragdoll-test.cjs`。前者是纯几何测试；后两者在真实 Edge/WebGL 载入实际 GLB，覆盖部位实弹伤害、动画刀刃接触、32 人模型、死亡到复活、5 秒清理、墙/高台物理碰撞及重开。运行示例：

```powershell
node tests/character-hitboxes-test.cjs
# 另一终端保持 node server.js 运行，下面脚本默认访问本机 8123 端口。
$env:FISH_TEST_URL='http://127.0.0.1:8123/'
node tests/browser-character-test.cjs
node tests/browser-ragdoll-test.cjs
```

浏览器脚本需开发环境安装 Playwright，或用 `PLAYWRIGHT_MODULE` 指向现有模块。将 `FISH_TEST_URL` 改为绝对 `file:///.../index.html` 可验证双击离线入口；游玩本身无需安装 Node/Playwright。

后续建议：先按固定相机与攻击动作调受击胶囊和武器平衡，再扩充角色皮肤。素材现有贴图在近处有细碎三角边线，本次保持源 GLB，不修改贴图；下一轮在烘焙源文件检查 UV 岛边缘留白和扩边。针对目标低配设备补角色/阴影 LOD、远处动画降频和物理质量档位；保留当前“逐角色复活清尸”和无尽 5 秒规则。专用第一人称动作、ADS、头发裙摆物理可以分别迭代，避免与命中判定耦合。

第一人称和跳跃回归位于 `tests/browser-view-jump-test.cjs` 与 `tests/fps-jump-test.cjs`；实际绘制、独立旁观视角、碰撞、动作/胶囊、空中死亡及复活均有覆盖。
