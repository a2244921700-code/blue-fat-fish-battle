# 角色语音与空间声音

2026-11-01 · OpenAI Codex（GPT-6）。

用户提供的 `deepseek娘、伪·Claude娘扔手雷1.mp3` 与 `deepseek娘、伪·Claude娘扔手雷2.mp3` 来自素材库 `蓝色肥鱼大作战专用/音效`，分别为 29,325 / 22,637 字节。原 MP3 字节不改动，两个角色共用，每次实际出手时随机二选一；玩家松开左键的实际出手瞬间播一次，AI 在动作出手事件播一次；选中手雷、死亡掉雷不额外喊话。

`voice-bank.js` 是唯一运行语音载荷，含上述两段与八段现有敌人 / Boss 语音，共 522,327 字节。每段只保存一次，所有角色共用；其余枪声、爆炸和音乐仍使用既有独立文件。八段旧独立语音 MP3 已归档到 `D:\CodexWork\蓝色肥鱼开发备份\2026-11-01-双阵营角色与投雷\assets\sfx`，没有在包内重复保存。`tools/build-voice-bank.cjs` 可重新生成语音表；旧录音从已有表保留，新投雷录音从用户素材目录读取。

采用内嵌 MP3 字节后，HTTP 和双击 `index.html` 都能由 AudioContext 解码，不会遇到 Chromium 对 file 媒体使用 MediaElementSource 时静音的问题。每段解码结果缓存一次。

`js/spatial-voice.js` 提供共用 WebAudio 管线：

- HRTF 定位跟随实际观察相机和发声角色的头部，具备左右及前后方位线索；远处按反比距离减弱，4 米参考距离、52 米外停止。
- 语音经高通去低频、距离低通及轻微早期反射。每 0.14 秒检查地图遮挡，隔墙时音量再乘 0.38、高频降至 1,100 Hz，参数平滑变化。
- 自己的投雷语音位于视角前下方，音量低于近处其他角色，避免直接贴在耳边喊；仍可清楚辨认台词。
- 同一角色只保留一条语音，总并发最多八条。死亡、退出清理声源；暂停保存已播放进度，恢复继续同一段；受设置面板音效音量控制。

`tests/browser-spatial-voice-test.cjs` 不只检查节点属性，还用 OfflineAudioContext 渲染原 MP3 采样，确认左右声道差异、远近音量和隔墙滤波；另检查实际游戏的随机分支、暂停恢复与死亡清理。file / HTTP 均验证。
